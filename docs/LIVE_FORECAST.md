# 실시간 "내일 예보" 쓰는 법

작성: 2026-11-12 · 코드: `src/forecast_tomorrow.py` · 확인: `src/check_forecast_tomorrow.py`

지금 공개된 자료만으로 **내일 육지 출력제어 위험도와 원인**을 계산해 시연 화면에 "내일 예보 (실시간)" 단추로 넣는다.
모델은 2026년 독립 시험의 주 모델(N+C, 공개 자료)과 같다. 태양광·원전 실적과 출력제어 이력은 전날 17시에 공개되지 않으므로 쓰지 않는다.

## 입력 세 가지

| 입력 | 어디서 | 인증키 |
| --- | --- | --- |
| 기상청 단기예보 (5개 지역 하늘상태·강수확률·최고기온) | 공공데이터포털 "기상청_단기예보 조회서비스" API | **필요** (무료, 자동 승인) |
| 전력수요 (5분 단위) | 전력거래소 EPSIS 실시간 전력수급 (학습에 쓴 2026년 수요와 같은 출처) | 필요 없음 |
| 공휴일 | `data/manual/holidays_kr.csv` | — |

## 처음 한 번: 기상청 인증키 받기 (팀원이 직접)

1. 공공데이터포털(data.go.kr) 로그인 → "기상청_단기예보 조회서비스" 검색 → 활용신청 (자동 승인)
2. 마이페이지 → 개발계정 → 그 서비스의 **일반 인증키(Decoding)** 복사
3. 저장소 맨 위에 `secrets_kma_key.txt` 파일을 만들고 키만 붙여 넣는다 (`.gitignore`에 있어 깃허브에 올라가지 않는다). 또는 환경변수 `KMA_SERVICE_KEY`

키는 절대 커밋하거나 채팅·발표자료에 붙이지 않는다.

## 매일 (또는 시연 전날)

```bash
pip install -r requirements.txt          # requests 포함
python src/forecast_tomorrow.py          # 17시 15분 이후 실행 → 내일 예보
python src/build_demo.py                 # 시연 화면에 반영 → demo/index.html
```

- **17시 15분 이후**: 오늘 17시 발표분 사용 (학습과 같은 조건)
- **14시 15분 ~ 17시 15분**: 14시 발표분으로 대신 (학습 때의 대체 규칙과 같다). 본선 당일 낮에 시연할 때가 이 경우
- 14시 15분 전에는 실행하지 않는다 (예보 발표 전)
- 결과는 `outputs/public/live_days.csv`에 한 줄씩 쌓인다. 날마다 돌리면 본선 때 "지난 며칠 실시간 예보와 실제 결과"를 보여 줄 수 있다
- 받은 원본은 `data/live/`에 저장된다 (깃허브에는 안 올라감)
- 어제 17시 발표분(예보 변화 항목용)은 전날 실행해 둔 저장본을 쓰고, 없으면 API로 다시 받는다. 못 받으면 그 항목만 빈칸

## 학습 때와 같은 계산인지 확인 (인터넷 불필요)

```bash
python src/check_forecast_tomorrow.py    # → "44일 × 26항목 모두 일치"
python src/forecast_tomorrow.py --offline 2026-05-05   # 과거 날짜를 API 응답 모양으로 바꿔 같은 계산 재현
```

저장소의 과거 예보·수요를 API 응답과 같은 모양으로 바꿔 실시간 계산 함수에 넣고, 특징 표의 값과 비교한다 (2026-11-12: 44일 × 26항목 일치).

## 경보 선과 한계

- 위험도 선과 확률 보정 곡선은 시험 때와 같은 규칙으로 정했다: 직전 12개월(2025-11 ~ 2026-10) 예보 결과에서 매우 높음 0.418(출력제어일의 절반 선), 높음 0.102(F1 최대), 주의 0.026(출력제어일 90% 선), 확률은 단조 회귀 보정 (`outputs/public/live_thresholds.json`, `src/explain_2026.py`가 만든다). 출력 예: "출력제어 확률 약 40% · 위험 높음"
- 모델은 실행할 때마다 특징 표(2023-01 ~ 2026-10-31) 전체로 다시 학습한다 (약 2초). 10월 2일 이후 정답은 게시판 실적이 아직 안 올라와 잠정이다
- 11~2월은 출력제어가 드문 계절이라 대부분 "낮음·주의"로 나올 것이다. 본선(12.3) 시연에서 "높음"이 안 나와도 정상이다
- 이 작업 공간에서는 기상청·EPSIS 서버에 접속할 수 없어 실제 API 호출은 팀 노트북에서 처음 확인해야 한다. EPSIS 요청 방식은 2026-11-12 브라우저에서 확인했다(하루 단위 요청, 2025-01-01 값이 저장소 원본과 일치)

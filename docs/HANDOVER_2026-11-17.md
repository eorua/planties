## 3. 새 시연 화면 (`demo-charts`)

"예보문" 구성이다. 위에서부터: 발표 시각 → "출력제어 확률 70% 이상" 큰 제목 + 위험도 4단계 띠 + 대비 → 그래프 → 달력·원인·실제 결과 보기 → 성적·위험도별 실제 비율 막대.

**그래프**: 지난 2주의 한낮(11~14시 평균) 전력수요 선 + 실제 출력제어(빨간 점, 아래 칸의 빨간 블록과 시간대) + 쉬는 날 회색 띠. "오늘" 세로 점선 왼쪽은 실제, 오른쪽 넓은 칸이 내일 예보(확률, 원인 상위 3개 이름, 점선 테두리의 위험도). "실제 결과 보기"를 누르면 점선 테두리가 채워진 블록("실제 있음 · 10~17시") 또는 흰 칸("실제 없음")으로 바뀐다.

**사용자와 정한 것 (다시 뒤집지 말 것)**
- **기준선과 칠한 영역은 넣지 않는다.** 2주 평균, 평일 최저를 차례로 써 봤지만 수요에는 출력제어 문턱값이 없어서(7월은 55~66GW에서도 발생, 12월은 45GW에도 없음) 어떤 선도 근거를 댈 수 없다. 강조는 빨간 점과 블록으로만 한다.
- **화면은 예보 시점(전날 17시)에 알 수 있는 것만 보여 준다.** 예보일의 실제 값은 "실제 결과 보기"를 누른 뒤에만 나온다.
- **"어제"가 아니라 "오늘".** 화면은 전날 17시에 내일을 예보하는 장면이므로 원인 문구의 "어제"를 표시할 때 "오늘"로 바꾼다(`parse()`에서 치환).
- **최근 30일 확률 막대 그림은 뺐다.** 헛경보가 먼저 눈에 들어와 손해였다.
- **수요와 태양광을 겹친 그림은 안 된다.** 공개 태양광은 시장 거래분(약 5GW)뿐이라 수요(약 50GW)와 한 축에 못 그린다.
- **"전날 수요가 평소보다 9.6GW 낮다" 같은 문구는 쓰지 않는다.** 평일이 섞인 평균과 주말을 비교한 것이라 부풀려진 숫자였다.
- **대비 문구는 위험도별 고정 문구다.** "AI가 대비책을 만든다"고 말하면 안 된다.
- **17시 기준인 이유**: 기상청 단기예보 발표 시각 중 근무 시간 안의 마지막이라서.
- **내일 칸의 "70%" 아래 작은 "이상"**: 옆에 붙이는 안, 같은 크기로 쓰는 안을 다 해 보고 지금 모양으로 정했다.
- **디자인**: 어두운 대시보드형 시안 세 개는 "AI 냄새가 난다"는 이유로 버렸다. 흰 바탕, 색은 위험도 색만, 공공기관 예보문 톤. 참고한 곳: 영국 carbonintensity.org.uk, CAISO Today's Outlook, 개인 프로젝트의 "지금 선으로 실제와 예측을 나누는 그래프".

**예선용 캡처** (`docs/slides/captures/`, 2025-11-02 예보): `01_예보화면.png`(1장·7장 큰 화면), `02_달력.png`, `03_그래프_예보.png`, `04_그래프_실제결과.png`, `05_실제결과_문구.png`. 03과 04는 같은 구도라 나란히 놓으면 점선→블록 변화만 보인다. 다시 뽑으려면 Playwright로 `demo/index.html`을 열고 `sel='2025-11-02'; cur=new Date(2025,10,1); reveal=false; cal(); show();`를 실행한다(폭 1080, 배율 3).

## 5. 작업 환경에서 알아 둘 것

- **Pretendard 글꼴**: 대회 템플릿 지정 글꼴. 사용자 컴퓨터의 `Downloads\Pretendard-1.3.9\public\static\*.otf`에 있다(설치는 안 된 상태로 보임). PPT를 정확히 그려 보려면 이 파일들을 가져와 `~/.fonts/`에 넣고 `fc-cache -f`를 돌린 뒤 LibreOffice로 변환한다.
- **사용자 컴퓨터**: Windows, 연결 폴더는 `C:\Users\admin\Downloads`. 저장소 사본은 `Downloads\benefit-radar\planties`(`git pull` 필요). 파워포인트는 무료판이라 "PDF로 내보내기"가 안 된다(인쇄 → "Microsoft Print to PDF"는 된다). 한쇼는 설치돼 있지 않다.
- **기상청 인증키**는 사용자 노트북의 `secrets_kma_key.txt`에만 있다. Claude가 저장하거나 문서에 적지 않는다. 로그인·비밀번호 입력은 사용자가 직접 한다.
- 학습을 다시 돌릴 때는 세 변형(`full`, `posted`, `public`)을 한 번에 하나씩 돌린다.

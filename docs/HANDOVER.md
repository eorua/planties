### 꼭 알아야 할 함정
1. **시간 기준이 자료마다 다르다.** 전력 자료는 1~24시 번호(시간 끝 기준), 기상 관측은 한국 시간 0~23시, **기상 예보는 국제표준시(UTC)** → 9시간 더해서 써야 한다. EPSIS는 HH:05~(HH+1):00 평균 = 시간 번호 HH+1.
2. **태양광 파일에 지역 합계 행(육지, 제주)이 섞여 있다.** 전국 합계는 `region_level == "시도"`만 더한다. 섞어 더하면 두 배가 된다.
3. **"발전량"이 아니라 "시장 거래량"이다.** 지붕 태양광처럼 시장 밖 발전은 빠져 있다. 발표에서 용어를 정확히.
4. **빈칸은 0이 아니다.** 정리본은 빈칸을 빈칸으로 둔다. 0으로 볼지는 특징 단계에서 정하고 이유를 적는다.
5. **제주 풍력 출력제어 파일만 시간 칸이 "제어량(MWh)"**이다. 나머지는 "출력제어/0" 표시.
6. **다음 날 실제 기상·수요를 입력에 넣으면 안 된다** (답을 미리 보는 것). 분석·설명용으로만.
7. **시험 결과를 본 뒤 설정을 바꾸지 않는다.** 2026년 시험은 계획서대로만 돌리고, 나쁘게 나와도 그대로 보고한다.

### 원본에서 발견해서 처리한 결함
- 태양광 원본의 "1,028.44" 같은 천 단위 쉼표 값이 숫자로 안 읽히던 문제 → 수정 (이전 특징 파일은 이 값을 0으로 넣었음, 폐기)
- 기상청 예보 2023·2024년 파일에 깨진 날짜 블록 → 하루 단위로 다시 받아 363일 → 15일로 줄임. 결측 표시값 -999.9(2023-11-07 하늘상태)를 더해 최종 20 조합·일이 빔
- 출력제어 제어지역 오타("감원"→강원 등) → 원문 유지하고 보정 열 따로

## 5. 다시 만들기

```bash
python src/build_clean.py      # 전력·기상 관측 raw → clean
python src/build_forecast.py   # 기상 예보 raw → clean (검증 658개)
python src/build_extra.py      # EPSIS 실시간 수급(시간별), 게시판(날짜별) 정리본
python src/build_features.py   # clean → 특징 표 (data/features, 1,400일)
python src/manifest.py write   # 지문 기록 (build 직후에만)

# 공개 자료 모델 = 발표 본 숫자, 시연 화면 (outputs/public/)
PLANTIES_VARIANT=public python src/train.py          # 2025년 평가 (약 2분)
PLANTIES_VARIANT=public python src/explain.py        # 위험도·원인·전력거래소 공지 비교 (2025년)
PLANTIES_VARIANT=public python src/test_2026.py      # 2026년 독립 시험 (계획: docs/TEST_2026_PLAN.md, 약 5분)
PLANTIES_VARIANT=public python src/explain_2026.py   # 2026년 위험도·원인 (시연용, 약 20초)
python src/build_demo.py       # 시연 화면 demo/index.html (브라우저로 바로 열림, 인터넷 불필요)

# 실시간 정보 모델 (비교용, outputs/): 위 네 줄을 PLANTIES_VARIANT 없이 실행
python src/manifest.py verify  # 원본·정리본이 바뀌지 않았는지 확인 → "문제 0개"
```

**원본(data/raw)과 정리본(data/clean)은 손으로 고치지 않는다.** 엑셀로 열어 저장만 해도 지문이 바뀌어 `verify`에서 걸린다. 바꿀 게 있으면 코드를 고치고 다시 실행한 뒤 CHANGELOG에 적는다.

## 9. 발표에 쓸 거리

- **문제 크기:** 육지 출력제어 2023년 2일 → 2025년 82일 (40배), 2026년은 6월 중순까지 이미 59일
- **계절성:** 봄·가을 한낮 수요가 가장 낮고(55~57GW, 여름·겨울은 70~78GW) 태양광은 비슷하게 나와서 남는 전기가 생긴다. 2025년 최저 수요는 5월 4일(연휴) 12시 35.8GW
- **공휴일:** 출력제어 발생일 중 19일이 공휴일 (2025년 추석 연휴 6일 연속 등)
- **규칙 대 모델:** 공개 자료만으로는 큰 차이가 없다(시험 0.59 대 0.49, 검증 0.61 대 0.62). 실시간 정보가 있으면 모델 0.78 대 규칙 0.52. 이 차이를 "출력제어 실적을 실시간 공개하면 예보가 이만큼 좋아진다"는 정책 제안으로 쓴다
- **전공 연결:** 팀명 플랜티즈 = 플랜트 산업, 출력제어 = 발전 플랜트 출력 조절. 전력시스템 해석(경제급전) 수업 내용과 연결
- **한계(먼저 밝힐 것):** 송전망 제약, 원전 정비 일정, 양수·ESS 운전 계획은 공개 자료가 없음. 게시판 제어 사유가 대부분 "전력망 제약"이라 이 부분이 성능의 상한. 시험 사례가 27일이라 숫자가 ±0.15 흔들림. 태양광은 정산값으로 학습(운영에서는 실시간 추정치). 헛경보 수는 경보 기준 하나에 15~31번으로 흔들림

# 2026년 독립 시험 계획 (사전 등록)

작성: 2026-11-11, **2026년 예측 결과를 보기 전에** 정하고 저장소에 올린다. 결과를 본 뒤에는 이 계획을 바꾸지 않는다.

## 왜 하나
- 2025년 하반기 시험(출력제어 27일)은 작아서 결과가 ±0.15씩 흔들린다.
- 개선 실험에서 "새 항목(더위·추위, 같은 종류 날 수요, 예보 변화)"이 검증과 시험에서 엇갈렸다.
- 2026년은 모델 개발에 한 번도 쓰지 않은 기간이고, 출력제어가 70일 있다.

## 제약
2026년 시간별 태양광 거래량과 원전 출력은 아직 공개되지 않았다 (2027년 예정). 그래서 **태양광·원전 입력을 뺀 모델**로 시험한다. 수요는 EPSIS 실시간 전력수급(5분 단위)으로 채운다 (2023~2025 기존 수요와 오차 중앙값 0.11%).

## 기간과 정답
| 구분 | 기간 | 정답 출처 | 출력제어일 |
| --- | --- | --- | --- |
| 시험 1 (주) | 2026-01-01 ~ 2026-06-13 | 전력거래소 공식 실적 | 59 |
| 시험 2 (보조) | 2026-06-14 ~ 2026-10-31 | 전력거래소 게시판 실적 (공식과 겹치는 149일 모두 일치) | 11 |

## 방식 (본 모델과 같음)
- 매달 1일에 그 전날까지의 모든 자료(2023-01부터)로 다시 학습 → 그달 예측
- 그래디언트 부스팅, 설정은 본 모델과 같다 (학습률 0.1, 깊이 3, 반복 300)
- 경보 기준: 매달 직전 12개월 예측 결과에서 F1 최대 (출력제어 15일 미만이면 기간 확장)

## 모델 (넓힌 검증 2024-03 ~ 2025-06 PR-AUC로 미리 고름)
| 이름 | 입력 | 넓힌 검증 | 역할 |
| --- | --- | --- | --- |
| **N+C** | 태양광·원전 뺀 기본 항목 + 새 항목 6개 | **0.459** | **주 모델 (미리 지정)** |
| N+S+C | N+C + 공급능력·예비율(EPSIS) | 0.456 | 비교 |
| N | 태양광·원전 뺀 기본 항목 | 0.435 | 비교 (새 항목 효과 확인용) |
| N+S | N + 공급능력·예비율 | 0.438 | 비교 (공급능력 효과 확인용) |
| 규칙 | 봄·가을 + 쉬는 날 + 맑음 + 최근 출력제어 | — | 기준선 |
| 전력거래소 전날 전망 공지 | 게시판의 "출력제어 전망" 공지 | — | 운영자 예측과 비교 |

## 보고할 것
- 시험 1·2와 합계: PR-AUC(95% 범위), 잡은 날·헛경보·놓침, 경보 정확도
- 새 항목 효과: N+C 대 N (2025년의 엇갈린 결과를 판정)
- 공급능력 효과: N+S 대 N
- 전력거래소 전날 공지와 같은 날짜에서 비교 (공지는 예/아니오 하나라 재현율·정밀도로 비교)
- 결과가 나쁘게 나와도 그대로 보고한다

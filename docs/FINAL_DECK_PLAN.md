## 시연 5분 대본 뼈대

1. (30초) 화면 소개: "2025년 날짜를 고르면, 그 전날 17시에 알 수 있던 정보만으로 낸 예보를 그대로 보여 줍니다."
2. (1분 30초) **2025-11-02(일)**: 위험 높음 → 원인 "쉬는 날, 낮은 전력수요" → 대비 3가지 → "실제 결과 보기" → 10~17시 출력제어, 사유 전력망 제약. 전력거래소 전날 공지는 없었던 날이라는 점을 짚는다.
3. (1분) **2025-07-12(토)**: 토요일이라 위험 높음으로 봤지만 실제로는 없음(헛경보). 한여름이라 냉방 수요가 커서 전기가 남지 않았다 → 모델이 기온(냉방 수요)을 충분히 반영하지 못하는 한계. 다음 단계(기온 항목)로 연결.
4. (1분) **2025-09-20(토)**: 위험 주의, 실제로는 10~17시 출력제어 → 놓친 날. 예보는 흐리거나 비였는데 게시판 사유는 전력망 제약 → 공개 자료로는 알 수 없는 송전망 정보의 한계. 전력거래소 전날 공지도 없었던 날.
5. (1분) 달력에 "실제 출력제어 표시"를 켠다. 10월: 출력제어 14일 중 12일이 빨간 날(높음), 2일이 노란 날(주의)이다(헛경보 12일). 7~12월 초록 날(낮음) 44일에는 점이 하나도 없다.

6. (시간이 남으면) "2026년 독립 시험" 단추 → **2026-05-05(어린이날)** 위험 높음(맑음 예보 100%, 낮은 수요) → 실제 9~17시 출력제어. 실제 출력제어 표시를 켜고 "봄 48일 중 46일"을 보여 준다. 9~10월 헛경보가 많다는 점도 짚는다.
